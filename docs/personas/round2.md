# Persona round 2: roles and expectations

Premise for everyone: a resident of a metropolitan Indian city (Mumbai, Delhi NCR,
Bengaluru, Hyderabad, Chennai, Kolkata, Pune), using the EatOS web build on a phone
(390 px wide) at least once a day. Each persona has expectations. An expectation that
fails is a finding; one that is exceeded is a delight. Severity: SAFETY-BLOCKER (could
harm), BUG, UX, CONTENT-GAP.
